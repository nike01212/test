# 最小需求文件（MVP PRD）：新聞標的整理與自選股清單

2026年10月23日 · @簡單 · 依據：PRD.md 切出的最小版本（第 2 版：依發起人決定，把標籤、國際大廠、CSV、休市行事曆、圖片辨識、拆分預覽、勾選匯出、漲停續看、連續統計納入範圍）

---

# 要解決的問題

投資群每天收盤後在 LINE 丟一堆新聞和 memo，大家要各自翻完、判斷是哪幾檔股票，再一檔一檔加進券商 App 自選，又慢又容易漏。這版要解決的事：把當天貼進來的資料變成一份「已去重、已對上代號、看得出在講什麼」的個股清單，讓大家開盤前能最快把股票加進自選，並且追蹤哪些標的收盤漲停、連續被提到。

# 解法（高層次）

一個只限群組使用、免費架設的小網站，主線是「貼入 → 預覽確認 → 對代號 → 清單 → 匯出」，收盤後再加上漲停比對：

1. **貼入**：一個大文字框，貼網址、文字，也可以貼上或拖曳圖片（每天約 20 張以內），三種可以混在一起。
2. **拆分預覽**：系統自動拆成一則一則，清掉網址的追蹤參數與 App 推廣文字，並標出每則的類型（網址、文字、圖片）。送出前，使用者可以合併、刪除、修改類型。
3. **取內文**：網址自動抓內文，抓不到就標「抓取失敗」，讓人改貼文字。網址去重。圖片用免費的文字辨識（OCR）轉成文字，辨識不準可以人工貼文字修正；辨識完就刪掉圖片。
4. **對代號**：用證交所與櫃買中心的官方名稱與代號清單比對；對不到或有歧義的標「待確認」，由人處理。
5. **標籤**：依固定的標籤清單（例如漲價、訂單、營收創高、合作、擴產、轉型、調升目標價）幫每則貼上標籤。標籤只描述內容，不代表利多或利空，可由人修改。
6. **國際大廠**：比對全球市值前 100 名的公司名單（含常見中英文別名），寫出合作對象的公司名稱。
7. **當日清單**：以個股為單位，顯示代號、名稱、被幾則提到、標籤、合作對象，以及各則的標題、連結、提到該股的原文句子（最多 2 句）。可以手動刪除誤判的個股、新增漏掉的個股。
8. **所屬交易日**：載入證交所公布的休市行事曆。交易日 09:00 前貼入歸當天，其餘歸下一個開盤日；颱風假等臨時休市由人手動改日期。
9. **匯出**：每檔股票可以勾選，勾選狀態只存在各人的瀏覽器。可以選「只匯出已勾選」或「當天全部」，格式有一鍵複製代號（一行一個）、.txt、CSV（代號、名稱）。超過 60 檔時，依被提到次數排序，自動切成 A、B 組（例如 1024-A）。另外提供「逐檔快速加入」模式：大字一次顯示一檔，按「下一檔」，方便在富邦e點通手動輸入。
10. **收盤漲停續看清單**：每個交易日收盤後，用交易所公布的收盤資料比對當天清單裡的個股，只算收盤漲停（收盤價等於漲停價），自動產出隔天的續看清單，可以手動增減，匯出時單獨成一組。每日漲停紀錄會保留。
11. **連續被提到的統計**：用每日提及紀錄與交易日曆計算每檔連續被提到幾個交易日，週末與休市日不算中斷，並顯示在清單上。
12. **保存**：只存代號、名稱、標題、網址、擷取句、標籤、合作對象、所屬交易日與漲停紀錄，不存全文，所以不需要定時刪除。可以切換日期，看過去的清單。
13. **存取**：輸入一組群組密碼才能進入，並設定不讓搜尋引擎收錄。標籤清單與國際大廠名單由發起人用設定檔維護，不做後台。

# 使用者故事

- 身為群組成員，我想**把 LINE 裡的網址、memo 和報紙照片整段貼進一個框**，以便不用一則一則分開處理。
- 身為群組成員，我想**送出前先看到拆好的每一則，必要時合併、刪除或改類型**，以便確保系統沒有拆錯。
- 身為群組成員，我想**讓報紙照片自動轉成文字，辨識不準時可以自己修正**，以便照片裡的標的也能列入清單。
- 身為群組成員，我想**讓系統自動找出內容提到哪幾檔股票、對上正確代號**，以便不用自己邊讀邊查代號。
- 身為群組成員，我想**看到每檔股票的標籤和國際大廠合作對象**，以便快速知道新聞在講什麼。
- 身為群組成員，我想**看到同一檔股票被幾則新聞提到、原文怎麼說**，以便自己判斷要不要放進自選。
- 身為群組成員，我想**在網址抓不到內容時改貼文字**，以便資料不會漏掉。
- 身為群組成員，我想**刪掉誤判的個股、補上漏掉的個股**，以便清單正確。
- 身為群組成員，我想**勾選我要的個股，只匯出勾選的那些**，以便清單符合自己的判斷。
- 身為群組成員，我想**匯出 CSV（代號、名稱）**，以便匯入其他軟體或試算表。
- 身為發起人，我想**開盤前一鍵複製代號清單，或用逐檔快速加入模式照著輸入**，以便用最短時間把股票加進富邦e點通自選。
- 身為發起人，我想**超過 60 檔時自動拆成 A、B 兩組**，以便配合e點通每組最多 60 檔的限制。
- 身為群組成員，我想**假日、週末貼的資料自動歸到下一個開盤日**，以便不用自己改日期。
- 身為群組成員，我想**收盤後自動拿到「今天清單裡收盤漲停」的續看清單**，以便隔天第一時間追蹤。
- 身為群組成員，我想**看到每檔股票連續被提到幾個交易日**，以便分辨一次性消息和持續發酵的題材。
- 身為群組成員，我想**切換日期查看以前的清單**，以便回頭查某檔股票哪天被提過。
- 身為發起人，我想**只有知道密碼的人才進得來**，以便資料只在群組內流通。

# 不做什麼（Out of Scope）

- **用關鍵字篩選重點句**（理由：篩錯反而會漏掉資訊；關鍵字已經用在標籤上，重點句直接列出提到該股的原文就好。）
- **AI 摘要**（理由：第一版要維持零成本，Claude Pro 訂閱不含 API 用量；規則式擷取加上標籤已經夠用。）
- **判斷利多或利空**（理由：已定案由每個人自己判斷，系統只負責整理事實。）
- **儲存全文，以及 7 天後自動刪除**（理由：一開始就不存全文，就不需要排程刪除，也同時降低版權和券商 memo 禁止轉發的風險。）
- **未歸屬個股區**，例如沒有指名個股的黃仁勳談話（理由：無法匯出成自選，對核心目標沒有幫助；需要的人可以自己手動新增個股。）
- **多家券商的專用匯入格式**（理由：其他朋友用哪家券商還沒調查；目前的 .txt 和 CSV 已經通用。）
- **富邦專用匯入檔、自選同步整合**（理由：富邦電腦版能不能匯入、能不能同步到手機都還沒驗證，而且同步是整批覆蓋，有清掉持股群組的風險。）
- **貼入者暱稱、「系統判斷或人工修改」的紀錄**（理由：30 人的小群組先不需要追蹤是誰貼的、誰改的；之後要做更深入的統計時再加。）
- **管理員後台與帳號系統**（理由：一組群組密碼就夠了；標籤與大廠名單用設定檔維護，要刪資料可以直接在清單上刪。）
- **即時報價**（理由：發起人會在券商 App 看盤和下單，網站不需要重做報價；漲停比對只用收盤資料。）
- **「漲停後隔天續漲比例」的分析報表**（理由：要先累積一段時間的漲停紀錄才有意義；這版先把資料存好，報表之後再做。）
- **匯入過去 LINE 的歷史資料**（理由：從上線當天開始記錄就好，整理舊資料的成本高、效益低。）

---

**開發前要先確認的事**：

1. 免費雲端服務的額度與條款，要能放下後端、資料庫，並支援排程與文字辨識。
2. 交易所收盤資料什麼時候公布、怎麼取得，漲停續看清單要用。
3. 免費文字辨識工具對工商時報版面照片的實際準確度。

**判斷新需求的原則**：之後如果冒出新想法，先問「沒有它，明天開盤前還能不能把股票加進自選？」答案是「能」，就先放進上面的清單，不放進這一版。
