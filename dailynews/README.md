# 新聞標的整理

需求見 [PRD-MVP.md](PRD-MVP.md)，實作順序見 [PLAN.md](PLAN.md)，免費額度見 [FREE-TIER.md](FREE-TIER.md)。

架在 Cloudflare 免費方案上：Workers（網站和後端）＋ D1（資料庫）。

## 檔案在哪裡

| 路徑 | 內容 |
| --- | --- |
| `src/index.ts` | 後端入口：每個請求都先檢查有沒有登入，再決定要給什麼 |
| `src/auth.ts` | 群組密碼、登入 cookie、密碼輸錯太多次的限制 |
| `src/api.ts` | 清單的 API：貼入、刪除、手動新增、處理待確認、改日期 |
| `src/tradingDay.ts` | 所屬交易日規則（09:00 前歸當天，其他歸下一個開盤日） |
| `public/` | 網頁本身（登入頁、今日清單頁） |
| `public/matcher.js` | 在瀏覽器裡找出文字提到的個股（伺服器 CPU 有限，比對放在這裡做） |
| `public/export.js` | 匯出：拆 A、B 組、複製用的代號、.txt、CSV |
| `public/marks.js` | 勾選和「已加入」標記的存放（只存在各人的瀏覽器） |
| `public/data/stocks.json` | 上市櫃代號與名稱，由 `npm run update-data` 產生，不要手改 |
| `public/data/holidays.json` | 證交所休市日，由 `npm run update-data` 產生，不要手改 |
| `public/data/name-rules.json` | 比對規則：別名、容易混淆要「待確認」的詞、要略過的一般詞彙（手動維護） |
| `scripts/update-data.mjs` | 從證交所、櫃買中心抓上面兩個資料檔 |
| `tests/` | 比對、交易日規則、匯出分組、勾選存放的測試（`npm test`） |
| `migrations/` | 資料庫的表格定義 |
| `wrangler.jsonc` | Cloudflare 的設定 |

## 第一次上線

在終端機進到這個資料夾（`dailynews`）後，依序執行：

1. 登入 Cloudflare（會打開瀏覽器；沒有帳號就先免費註冊，不用綁卡）：

   ```bash
   npx wrangler login
   ```

2. 部署網站。第一次會問你要用什麼 workers.dev 子網域（網址的一部分，例如 `你取的名字.workers.dev`），也會自動建立資料庫：

   ```bash
   npm run deploy
   ```

3. 設定群組密碼。輸入時畫面不會顯示字，打完按 Enter；設定完馬上生效，不用重新部署：

   ```bash
   npx wrangler secret put GROUP_PASSWORD
   ```

完成後打開 `https://dailynews.你的子網域.workers.dev`。

## 日常操作

- **改群組密碼**：重新執行第 3 步。改完之後所有人都會被登出，要用新密碼重新登入。
- **更新網站**：`npm run deploy`（有新的資料庫 migration 也會一起套用）
- **更新代號清單和休市日**：`npm run update-data`，再 `npm run deploy`。有新股上市、或證交所公布明年休市日（通常在年底）之後跑一次。行事曆還沒公布的年份，系統只會排除週末和元旦，交易日檢查會提醒。
- **調整比對規則**：改 `public/data/name-rules.json`，再 `npm run deploy`。例如某個常見詞一直被誤判成股票，就加進 `ignore`；某檔的常見叫法對不到，就加進 `aliases`。
- **本機測試**：`npm run dev`，打開 http://localhost:8787 。本機用的測試密碼在 `.dev.vars`（不會上傳）。
- **自動測試**：`npm test`（比對規則、交易日規則、匯出分組、勾選存放）

## 比對個股的規則

- 名稱來源：證交所、櫃買中心的官方簡稱，加上公司全名去掉「股份有限公司」「科技」等字之後的叫法（例如「全新光電」「日月光」），以及 `name-rules.json` 的別名。
- 名稱後面緊接代號（例如「台積電(2330)」「統一 1216」）就直接確定。
- 標「待確認」的情況：容易和一般用語混淆的名稱（例如「統一」「創意」）、同一個名稱對到兩檔（「台南」和「台南-KY」）、名稱和括號裡的代號對不起來、括號裡的代號不在上市櫃清單（例如 ETF）。
- 只存標題和提到個股的句子（每檔每則最多 2 句，太長的句子只留前後一段），不存全文。

## 匯出到自選

- **勾選**：清單上每檔都可以勾選。勾選和逐檔快速加入的「已加入」標記只存在各人的瀏覽器裡，依日期分開存，不會寫進資料庫，也不會跟到別台裝置。超過 90 天的紀錄會在打開網頁時自動清掉。私密瀏覽這類不能存資料的情況，頁面一樣能用，只是重新整理後勾選就不見了。
- **範圍**：可以選「當天全部」或「只匯出已勾選」，有勾選時預設是後者。待確認的個股不會匯出。
- **分組**：依被提到的則數由多到少排（則數一樣就依代號）。60 檔以內只有一組，組名是月日（例如 1028）；超過 60 檔，每 60 檔切成一組：1028-A、1028-B……（e點通每組最多 60 檔）。
- **格式**：複製代號（一行一個）、.txt（內容和複製的一樣）、CSV（代號、名稱兩欄）。CSV 開頭有 UTF-8 BOM，Excel 和 Numbers 打開中文才不會變亂碼。
- **逐檔快速加入**：一次用大字顯示一檔。按「已加入，下一檔」會標記並前進，點代號可以複製。關掉再打開，會從第一檔還沒加入的接著開始。

## 安全設計

- 沒有輸入密碼前，除了登入頁以外的東西都拿不到（網頁和資料 API 都會擋）。
- 登入後保持 30 天，之後要重新輸入。
- 同一個網路位置 15 分鐘內輸錯 10 次，會暫時擋下。
- 每個回應都帶 `X-Robots-Tag: noindex`，網頁裡也有 `<meta name="robots" content="noindex">`，搜尋引擎不會收錄。`robots.txt` 刻意不擋爬蟲，搜尋引擎才讀得到這個 noindex 標記。
